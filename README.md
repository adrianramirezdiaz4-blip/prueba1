# Acuerdo privado — flujo sin base de datos

1. Sube `index.html` a un repositorio de GitHub llamado `acuerdo-privado`.
2. En Settings → Pages, selecciona Deploy from a branch, rama `main`, carpeta `/ (root)`.
3. Abre la página. La primera persona completa ambos nombres, fecha y datos opcionales; firma y pulsa **Guardar invitación para WhatsApp**.
4. Adjunta manualmente el HTML descargado en WhatsApp. El botón WhatsApp solo prepara el texto: el navegador no permite adjuntar automáticamente un archivo local.
5. La segunda persona abre el HTML recibido en un navegador, revisa el documento, firma y pulsa **Firmar y guardar acuerdo final**.
6. Descarga el HTML final. Para conservarlo como PDF, pulsa Imprimir / Guardar como PDF.

No hay base de datos, sala en vivo ni sincronización. El borrador se guarda localmente en el navegador del primer dispositivo. GitHub Pages no almacena cambios de los visitantes. El archivo de invitación contiene nombres y la primera firma; compártelo solo con la persona correspondiente.

El acuerdo es orientativo y no sustituye asesoría jurídica. No establece multas por retirar consentimiento o terminar la relación. Uso exclusivo entre personas adultas.
